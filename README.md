# Odyssey ebook

English translation of Homer's *Odyssey* and the files used to build the EPUB.

## Layout

- `english/book-01.md` … `english/book-24.md` — line-for-line English books
- `scripts/build_ebook.py` — stdlib EPUB 3 builder
- `cover/cover-exact.jpg` — jacket image (SHA-256 `8c39436a4243ca11596380909b87c7962319d20cc24398493c7b5432b2252bc3`)
- `ebook/Odyssey.epub` — current EPUB build
- `ebook/Odyssey-Notes.md` — compiled notes
- `ebook/TRANSLATION-REPORT.md` — method report
- `REBUILD.md` — how to rebuild the EPUB

See `REBUILD.md` for builder paths and the required cover hash.
